# Your photographs go here

Upload your photographs into this folder. The website automatically includes files with these extensions:

- .jpg / .jpeg
- .png
- .webp
- .gif

You can also create subfolders inside `images` if you want to organise files; the gallery will include images from those subfolders too.

After you upload or remove photographs and push the changes to GitHub, the site rebuilds its image list automatically.

For best performance, use appropriately sized JPEG or WebP files. Keep an original backup of your photographs elsewhere.
